# Corresponding source code

The network-facing Hashcod signing adapter is published in this directory.

## Included

- `app/hashcod-docuseal-adapter.js`: browser-side signing adapter source.
- `app/hashcod-docuseal-adapter.html`: standalone demonstration page.
- `upstream/docuseal-master.zip`: unmodified upstream DocuSeal source archive.
- Original DocuSeal license and additional terms.
- Documentation and a packaging script.

## Excluded

The private Hashcod core is a separate program and is not linked into this
package. Private keys, passwords, tokens, database credentials, customer
documents, and customer records are not source code and are not included.
