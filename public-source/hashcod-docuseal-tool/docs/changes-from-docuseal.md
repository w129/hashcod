# Changes from DocuSeal

This package preserves an unmodified upstream DocuSeal source archive and adds a
small Hashcod-specific browser adapter. It is not presented as the complete
DocuSeal product.

The adapter adds:

1. Local PDF preview.
2. Typed or uploaded image signature.
3. Four signature placement presets.
4. Signer name and ISO timestamp metadata.
5. SHA-256 digest display for the source PDF.
6. A visible AGPL and source disclosure panel.

Hashcod cryptographic generators, customer records, commercial logic, and
private infrastructure remain outside this separated package.
