# Changes from Warp

This is a browser adapter, not a native Warp fork.

Hashcod adds:

- A compact file navigator and code editor.
- A command surface for local project operations.
- A sandboxed JavaScript execution iframe.
- CSP restrictions that block network access from executed code.
- Visible source and license disclosure inside Hashcod.

Hashcod does not embed Warp's native shell, agents, Drive, authentication,
operating-system terminal, or desktop runtime.
