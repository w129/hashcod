# Changelog

## 1.1.0

- Added multi-language profiles and cryptographic starter templates.
- Added SHA-256-backed compile plans for native languages.
- Added JSON validation, HTML/Markdown preview support, copy command and
  richer export manifests.
- Expanded the Hashcod UI with language controls and a preview panel.

## 1.0.0

- Added separated Hashcod browser programming workspace.
- Added local file tabs and localStorage persistence.
- Added sandboxed JavaScript runner with network access blocked.
- Added Warp attribution, exact upstream licenses, and reproducible fetch script.
